# Orca Enterprise

Orca Enterprise is a free service platform for mobile detailing, residential cleaning, commercial cleaning and transportation, including Orca School Pickup Service.

## Deployment
Designed for Railway with Node 20 and PostgreSQL. The app exposes `/health` and `/api/services`.

## Admin
The production admin dashboard uses username/password authentication with bcrypt password hashing and server-side sessions.
